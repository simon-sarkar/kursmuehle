# Kachel fürs Schulportal

Willst du Kursmühle als Kachel in das Portal deiner Schule oder eine andere Linkliste aufnehmen, nimm eines dieser
Bilder und als Ziel `https://kursmuehle.de`:

- `kursmuehle-kachel-512.png`, `-256.png`, `-128.png`: mit abgerundeten Ecken, in den Ecken transparent
- `kursmuehle-kachel-eckig-512.png`, `-256.png`, `-128.png`: volles Quadrat, für Portale, die die Ecken selbst runden
- `kursmuehle-kachel.svg`, `kursmuehle-kachel-eckig.svg`: dieselben Motive als Vektorgrafik

Beschriftung der Kachel: „Kursmühle“.
