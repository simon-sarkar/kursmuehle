# Gutachten 2.0-Plan – Perspektive Lehrkräfte (24.10.2026)

Unabhängiger Prüfagent (Opus) mit drei Personas: (a) Mathe, ByLKI im Schulbrowser auf verwaltetem Windows-PC, kein eigenes KI-Konto; (b) Englisch, iPad/Safari, fobizz, Kurs für morgen in der Freistunde; (c) Referendar, ChatGPT Plus. Prüfgegenstand `docs/entwicklung/2.0-plan.md`, Maßstab Abschnitt 1 (zehn Minuten, keine Doku, jeder Schritt ein Knopf).

Urteil: Für Persona (a) hält der Plan den Zehn-Minuten-Maßstab nicht; Ausstieg beim Aufruf im Schulnetz, beim späten Pyodide-Laden oder beim ersten Einfügen einer umformatierten Antwort. Zwingend: Probe auf verwaltetem PC vor dem Design mit einem Offline-Weg, der unter file:// läuft; Start mit drei Feldern; Parser nimmt ganze Chat-Antwort an und behandelt Abbruch/Korrektur blockweise; Pyodide vorab laden mit Ausweich; Mappe am nächsten Tag ohne Downloads-Ordner wiederfinden (verborgene Datei im Kurs).
