Kursmühle

Kurse wiederherstellen, die es noch nie gab.

Ein KI-Assistent baut aus einer Beschreibung oder aus eigenem Unterrichtsmaterial eine Kurssicherung (.mbz) für die ByCS-Lernplattform (Bayern, Moodle-basiert, früher mebis). Die Lehrkraft liest vorher ein kurzes Drehbuch, gibt es frei und stellt die Sicherung im eigenen Kurs wieder her. Abschnitte, Lesetexte, Übungen, Tests, Badges und Kursbild kommen fertig an.

Skill-Zip herunterladen Repository auf GitHub

Schnellstart

ChatGPT oder Claude

  1. Skill-Zip herunterladen.
  2. Zip hochladen und schreiben: „Entpacke das und lies SKILL.md.“ Dahinter den Kurswunsch, zum Beispiel „Mach mir eine Einheit zu Bruchrechnen für Jgst 6, 45 Minuten, Selbstlernkurs.“
  3. Drehbuch lesen, „passt“ sagen, .mbz herunterladen.

Code-Ausführung muss im Assistenten eingeschaltet sein.

ByLKI oder AIS-Chat

Diese Angebote führen keinen Code aus. Eine Fassung im Browser, die aus dem Drehbuch die Sicherung baut, kommt mit Version 2.0. Bis dahin: Drehbuch dort schreiben lassen, Bau mit ChatGPT, Claude oder einem Agenten.

Claude Code, Codex, eigener Agent

Repository klonen und dem Agenten die Seite für Fortgeschrittene geben: eigene Kurssicherung als Vorlage, eigene Designvorlagen, Textbausteine und Fachregeln, Zip neu packen.

Was dabei herauskommt

  • Kursformate Themen, Kacheln (mit Kachelbild je Abschnitt), Wochen, Ein-Themen, Komprimiert, Einzelaktivität.
  • Lesetexte als formatierte Textfelder und Seiten, Lesebuch, Buch; Übungen als Quiz, Zuordnen, Lernkarten, Lückentext, Geschichte mit Entscheidungen; Test mit Fragensammlung, Aufgabe, Forum, Abstimmung, Glossar, Datei und Verzeichnis.
  • Übungen auf Wunsch direkt auf der Kursseite ohne Nachladen, oder eine ganze Einheit als eine Seite mit Kapiteln.
  • Kursbanner und Kursbild, Badge am Ende, Nachlieferungen in einen laufenden Kurs, Freigabe nach Datum.
  • Vor dem Drehbuch prüft der Assistent gegen zehn didaktische Standardannahmen und eine Liste von Sprachmarkern.

Wiederherstellen auf der Plattform

  1. Kurs öffnen → Mehr → Kurs wiederherstellen → Datei hochladen → Wiederherstellen.
  2. Bestätigen: nur Weiter.
  3. Ziel: als neuen Kurs in eine Kategorie; oder in diesen Kurs mit „löschen und dann wiederherstellen“ (nur so kommt ein anderes Kursformat mit); oder „zusammenführen“ für Nachlieferungen, die hinten anhängen.
  4. Einstellungen: Weiter. Schema: bei Formatwechsel „Kurseinstellungen überschreiben: Ja“. Wiederherstellen.
  5. Danach Glossar-Einträge importieren (Glossar → Mehr → Einträge importieren, XML-Datei neben der Sicherung) und Badge aktivieren.

Übungs-Textfelder nicht mit „Einstellungen bearbeiten“ speichern: der Editor entfernt Skript und Stil. Änderungen laufen über das Drehbuch und eine neue Sicherung. Eine Sicherung darf höchstens 500 MB haben.

Rückmeldung

Ohne GitHub-Konto: Rückmeldung senden. Mit GitHub-Konto: Issue anlegen. Am meisten hilft: Fach, Jahrgangsstufe, Assistent, Dauer, und wo es gehakt hat. Gesammelte Rückmeldungen stehen in Erfahrungen.
