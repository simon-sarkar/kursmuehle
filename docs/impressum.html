Datenschutz

Die Mühle läuft in deinem Browser. Sie schickt nichts, was du eingibst, an einen Server; es gibt keinen, der Eingaben annimmt. Sie setzt keine Cookies und hat kein Tracking. Die Seiten laden nichts von anderen Adressen.

Damit eine angefangene Einheit nach dem Schließen des Tabs nicht verloren ist, sichert die Mühle sie im Speicher deines Browsers (IndexedDB). Dort bleibt sie, bis eine andere Einheit sie ersetzt, du sie mit „×“ verwirfst oder den Browserspeicher löschst; ich sehe davon nichts.

Den Text für den Chat kopierst du selbst in einen Chat deiner Wahl. Was dort eingefügt wird, unterliegt den Bedingungen dieses Chats.

Die Seiten liegen bei GitHub Pages (GitHub, Inc., USA). Beim Abruf speichert GitHub Zugriffsdaten wie die IP-Adresse in Protokollen; GitHub nimmt nach eigener Angabe am EU-US Data Privacy Framework teil (siehe die Datenschutzerklärung von GitHub). Auf diese Protokolle habe ich keinen Zugriff.
