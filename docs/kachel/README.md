# Kachel für das Schulportal

Wer Kursmühle als Kachel in das ByCS-Portal seiner Schule oder eine andere Linkliste aufnehmen will, nimmt eines dieser
Bilder und als Ziel `https://kursmuehle.de`:

- `kursmuehle-kachel-512.png`, `-256.png`, `-128.png`: mit abgerundeten Ecken, Hintergrund außerhalb transparent
- `kursmuehle-kachel-eckig-512.png`, `-256.png`, `-128.png`: volles Quadrat, für Portale, die die Ecken selbst runden
- `kursmuehle-kachel.svg`, `kursmuehle-kachel-eckig.svg`: dieselben Motive als Vektorgrafik

Beschriftung der Kachel: „Kursmühle“. Die Dateien entstehen aus `docs/make_logo.py` (gleiche Mühle wie das Logo).
